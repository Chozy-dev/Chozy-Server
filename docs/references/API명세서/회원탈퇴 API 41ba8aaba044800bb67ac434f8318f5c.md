# 회원탈퇴 API

API Path: /my/account
HTTP 메서드: DELETE
도메인: 마이 화면
상태: 시작 전

### 회원탈퇴 API

> 로그인한 회원의 비밀번호를 확인한 뒤 회원탈퇴를 처리합니다. 탈퇴 처리 후 해당 계정으로 서비스를 이용할 수 없도록 합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `password` | String | O | 회원탈퇴 확인을 위한 현재 비밀번호 |

```json
{
  "password": "ExamplePassword123!"
}
```

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "회원탈퇴가 완료되었습니다.",
  "data": null
}
```

## Response Data

없음

회원탈퇴 요청 시 현재 비밀번호를 검증합니다. 비밀번호가 일치하지 않으면 탈퇴를 진행하지 않습니다.

탈퇴 성공 시 해당 회원의 계정을 비활성화하고 로그인 및 토큰 재발급을 차단합니다. 기존 Refresh Token은 모두 무효화합니다. 기존 Access Token도 더 이상 회원 API에 접근할 수 없도록 계정 활성 상태를 검증해야 합니다.

탈퇴한 회원의 관심상품·알림 설정·개인별 사용량·분석 기록 등은 개인정보 처리방침과 데이터 보관 정책에 따라 삭제 또는 비식별화해야 합니다. 원본 상품 데이터와 모든 사용자에게 공통으로 제공되는 수집 데이터는 별도로 관리합니다.

회원 계정은 탈퇴 상태를 기록한 뒤 개인정보 보관·삭제 정책에 따라 처리합니다. 즉시 물리 삭제 여부, 재가입 처리 및 분석·평가 데이터 보관 기간은 개인정보 처리 정책에 맞춰 확정해야 합니다.

회원탈퇴 전에 프론트엔드는 최종 확인 화면을 표시합니다.

탈퇴 완료 후 프론트엔드는 인증 정보를 삭제하고 로그인 또는 홈 화면으로 이동합니다.

본인의 계정만 탈퇴할 수 있으며, 요청에서 별도의 사용자 ID를 받지 않고 JWT로 식별합니다.
