# 관심상품 판매 결과 기록 API

API Path: /favorites/{favoriteId}/sales-results
HTTP 메서드: POST
도메인: 관심 화면
상태: 시작 전

### 관심상품 판매 결과 기록 API

> 관심상품을 실제로 판매한 결과에 대한 사용자의 평가를 기록합니다. 이 기록은 정밀분석 점수와 실제 판매 결과를 비교하여 향후 점수 산정 기준을 개선하는 데 활용합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `favoriteId` | Number | O | 판매 결과를 기록할 관심상품 ID |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `result` | String | O | 판매 결과 평가 (`GOOD`, `AVERAGE`, `POOR`, `NOT_LISTED`) |

판매 결과 유형:

| 값 | 설명 |
| --- | --- |
| `GOOD` | 잘 팔렸어요 |
| `AVERAGE` | 그럭저럭 |
| `POOR` | 안 팔렸어요 |
| `NOT_LISTED` | 아직 안 올렸어요 |

```json
{
  "result": "GOOD"
}
```

## Response Form Example

### Success

```json
{
  "status": 201,
  "message": "판매 결과가 기록되었습니다.",
  "data": {
    "salesResultId": 701,
    "favoriteId": 501,
    "reportId": 2048,
    "source": "DOMEME",
    "productId": "12345678",
    "result": "GOOD",
    "scoreAtRecording": 75,
    "supplyConditionScoreAtRecording": 78,
    "marketConditionScoreAtRecording": 73,
    "recordedAt": "2026-11-17T15:20:00+09:00"
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `salesResultId` | Number | 생성된 판매 결과 기록 ID |
| `favoriteId` | Number | 관심상품 ID |
| `reportId` | Number | 해당 상품의 최초 등록 리포트 ID |
| `source` | String | 소싱처 (`DOMEME`, `OWNERCLAN`, `MANUAL`) |
| `productId` | String/null | 소싱처 상품번호 |
| `result` | String | 판매 결과 (`GOOD`, `AVERAGE`, `POOR`, `NOT_LISTED`) |
| `scoreAtRecording` | Number/null | 의견 제출 시점의 종합점수 |
| `supplyConditionScoreAtRecording` | Number/null | 의견 제출 시점의 공급 조건 점수 |
| `marketConditionScoreAtRecording` | Number/null | 의견 제출 시점의 시장 조건 점수 |
| `recordedAt` | DateTime | 기록 시각 |

점수와 상품 정보는 프론트엔드에서 전달받지 않고 서버에 저장된 값을 사용합니다. 기록 당시 점수를 함께 보관하여 이후 점수가 변경되어도 평가 근거가 유지되도록 합니다.

판매 결과는 관심중·판매중 상태와 관계없이 기록할 수 있습니다. `NOT_LISTED`를 선택하더라도 관심상품 상태를 자동 변경하지 않습니다.

POST 요청마다 판매 결과를 새로운 이력으로 저장하고, 관심상품 상세 조회 API의 `salesResult`에는 가장 최근 기록을 반환합니다. 이를 통해 사용자가 나중에 평가를 변경해도 이전 평가 이력을 보관할 수 있습니다.

판매 결과 기록은 무료 정밀분석 횟수를 차감하지 않습니다. 본인의 관심상품에 대해서만 등록할 수 있습니다.
