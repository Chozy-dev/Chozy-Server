# 관심상품 목록 조회 API

API Path: /favorites
HTTP 메서드: GET
도메인: 관심 화면
상태: 시작 전

### 관심상품 목록 조회 API

> 로그인한 사용자의 관심상품 목록을 조회합니다. 관심중·판매중 상태별로 구분하고, 점수순·변동순·최신순 정렬을 지원합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Query Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `status` | String | X | 상태 필터 (`INTERESTED`, `SELLING`). 기본값 `INTERESTED` |
| `sort` | String | X | 정렬 기준 (`SCORE`, `CHANGE`, `LATEST`). 기본값 `LATEST` |
| `page` | Number | X | 페이지 번호. 기본값 0 |
| `size` | Number | X | 페이지당 조회 개수. 기본값 20 |

정렬 기준:

- `SCORE`: 현재 비용투자 적합도 점수 높은 순
- `CHANGE`: 등록 시점 대비 점수 변동폭이 큰 순 (절댓값 기준) `[설계 제안]`
- `LATEST`: 최근 등록 순

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `counts` | Object | 관심상품 상태별 개수 및 한도 |
| `counts.interested` | Number | 관심중 상품 개수 |
| `counts.selling` | Number | 판매중 상품 개수 |
| `counts.total` | Number | 전체 관심상품 개수 |
| `counts.limit` | Number | 관심상품 등록 한도 |
| `items` | Array | 조회 조건에 맞는 상품 목록 |
| `items[].favoriteId` | Number | 관심상품 고유 ID |
| `items[].reportId` | Number | 최초 등록에 사용한 리포트 ID |
| `items[].source` | String | 소싱처 (`DOMEME`, `OWNERCLAN`, `MANUAL`) |
| `items[].productId` | String/null | 소싱처 상품번호 |
| `items[].productName` | String | 상품명 |
| `items[].productImageUrl` | String/null | 상품 대표 이미지 URL |
| `items[].supplierName` | String | 공급사명. 직접 입력 상품은 `공급사 직접 입력(API 미지원 사이트)` |
| `items[].status` | String | `INTERESTED`, `SELLING` |
| `items[].selectedOption` | Object/null | 등록할 때 선택한 판매 옵션 |
| `items[].selectedOption.optionId` | String | 옵션 식별자 |
| `items[].selectedOption.optionName` | String | 옵션명 |
| `items[].otherOptionStockouts` | Array/null | 선택한 옵션 이외의 현재 품절된 옵션 목록 |
| `items[].otherOptionStockouts[].optionId` | String | 품절된 다른 옵션의 식별자 |
| `items[].otherOptionStockouts[].optionName` | String | 품절된 다른 옵션의 이름 |
| `items[].otherOptionStockouts[].isCurrentlyOutOfStock` | Boolean | 현재 품절 여부. 이 배열에는 true인 옵션만 포함 |
| `items[].wholesalePrice` | Number | 현재 공급가(원). 직접 입력 상품은 최초 입력한 도매가 |
| `items[].stockQuantity` | Number/null | 현재 재고 수량. 확인 불가능하면 null |
| `items[].score` | Number/null | 현재 비용투자 적합도 점수(0~100) |
| `items[].scoreChange` | Number/null | 현재 점수 − 등록 시점 점수 |
| `items[].profitPerUnit` | Number/null | 현재 기준 예상 개당 마진(원) |
| `items[].marginRate` | Number/null | 현재 기준 예상 마진율(%) |
| `items[].createdAt` | DateTime | 관심상품 최초 등록 시각 |
| `items[].updatedAt` | DateTime | 상품 추적 정보가 마지막으로 갱신된 시각 |
| `pagination` | Object | 페이지 정보 |
| `pagination.page` | Number | 현재 페이지 번호 |
| `pagination.size` | Number | 페이지당 조회 개수 |
| `pagination.totalElements` | Number | 필터링 결과 전체 개수 |
| `pagination.totalPages` | Number | 전체 페이지 수 |
| `pagination.hasNext` | Boolean | 다음 페이지 존재 여부 |

`counts`는 상태 필터와 관계없이 사용자의 전체 관심상품을 기준으로 반환합니다.

점수가 계산 대기 상태이면 `score`와 `scoreChange`는 null이며, 점수순·변동순 정렬에서 마지막에 배치합니다.

공급가·재고·마진·점수는 서버가 보유한 최신 추적 데이터를 반환합니다. 목록 조회 자체가 상품마다 외부 API를 호출하지는 않습니다.

마진은 저장된 판매가·수수료·배송비와 갱신된 공급가를 기준으로 계산하며, 시장가와 시장 조건의 갱신 시각은 서로 다를 수 있습니다.

관심상품이 없으면 `items`는 빈 배열입니다.

옵션별 가격이 다른 상품은 관심상품 등록 시 선택한 옵션을 기준으로 공급가·품절 알림을 처리합니다. 선택하지 않은 다른 옵션의 품절은 알림을 발생시키지 않고 관심상품 목록 카드에 표시합니다.

`otherOptionStockouts`에는 선택한 옵션을 제외하고 현재 품절된 옵션만 반환합니다. 품절된 다른 옵션이 없다면 빈 배열(`[]`), 옵션 정보를 확인할 수 없다면 `null`을 반환합니다. 직접 입력 상품은 `null`을 반환합니다.
