# 로그인 API

API Path: /auth/login
HTTP 메서드: POST
도메인: 회원인증
상태: 시작 전

### 로그인 API

> 아이디와 비밀번호를 검증하고 로그인 성공 시 JWT Access Token 및 Refresh Token을 발급합니다.
> 

### Authentication

불필요

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `loginId` | String | O | 회원 아이디 |
| `password` | String | O | 비밀번호 |

```json
{
  "loginId": "chozy123",
  "password": "ExamplePassword123!"
}
```

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "로그인이 완료되었습니다.",
  "data": {
    "userId": 1024,
    "nickname": "초보셀러",
    "accessToken": "eyJhbGciOiJIUzI1NiJ9.example.signature",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9.refresh.signature",
    "tokenType": "Bearer",
    "expiresIn": 3600
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `userId` | Number | 로그인한 회원 식별자 |
| `nickname` | String | 사용자 닉네임 |
| `accessToken` | String | API 인증에 사용하는 JWT Access Token |
| `refreshToken` | String | Access Token 재발급에 사용하는 토큰 |
| `tokenType` | String | 인증 방식 (`Bearer`) |
| `expiresIn` | Number | Access Token 유효시간(초) |
