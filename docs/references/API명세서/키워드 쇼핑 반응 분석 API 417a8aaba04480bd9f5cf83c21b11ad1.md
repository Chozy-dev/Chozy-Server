# 키워드 쇼핑 반응 분석 API

API Path: /search/screenings/{screeningId}/shopping-analysis
HTTP 메서드: POST
도메인: 검색
상태: 시작 전

### 키워드 쇼핑 반응 분석 API

> 스크리닝 결과 카드에서 분야를 선택하면 해당 키워드의 쇼핑 클릭 추이를 조회하고, 4분면 해석 및 종합점수를 다시 계산합니다.
> 

### Authentication

불필요

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `screeningId` | String | O | 기존 키워드 스크리닝 결과 식별자 |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `keyword` | String | O | 쇼핑 반응을 분석할 키워드 |
| `categoryCode` | String | O | 선택한 네이버 쇼핑인사이트 분야 코드 |

```json
{
  "keyword": "니트 가디건",
  "categoryCode": "50000000"
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `keyword` | String | 분석한 키워드 |
| `categoryCode` | String | 선택한 쇼핑인사이트 분야 코드 |
| `categoryName` | String | 선택한 분야명 |
| `score` | Number | 쇼핑 반응을 포함해 다시 계산한 종합점수(0~100) |
| `searchGrowthRate` | Number/null | 작년 같은 시기 대비 검색 추이 증감률(%) |
| `shoppingGrowthRate` | Number/null | 작년 같은 시기 대비 쇼핑 클릭 추이 증감률(%) |
| `quadrant` | Object/null | 4분면 분석 결과. 필요한 추세 데이터가 없으면 null |
| `type` | String | 4분면 유형 (`GOLDEN_TIME`, `BUZZ_ONLY`, `HIDDEN_DEMAND`, `DECLINING`) |
| `label` | String | 4분면 해석 제목 |
| `description` | String | 4분면 해석 안내 문장 |
| `shoppingTrend` | Object/null | 쇼핑 클릭 추세 데이터 |
| `last30Days` | Array | 최근 30일 쇼핑 클릭 추세 |
| `last12Months` | Array | 최근 12개월 쇼핑 클릭 추세 |
| `date` | String | 일별 추세 기준 날짜 |
| `month` | String | 월별 추세 기준 월 |
| `value` | Number | 쇼핑인사이트 상대 클릭 지수 |
