# 키워드 스크리닝 API

API Path: /search/screenings
HTTP 메서드: POST
도메인: 검색
상태: 시작 전

### 키워드 스크리닝 API

> 입력한 최대 10개의 키워드에 대해 네이버 검색광고 및 데이터랩 데이터를 조회하고, 검색량·경쟁강도·검색 추이를 바탕으로 종합점수를 계산합니다.
> 

### Authentication

불필요 (로그인 회원은 JWT 선택 전달 가능)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | X | `Bearer {accessToken}`. 전달하면 로그인 회원의 최근 스크리닝 기록을 서버에 저장 |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `keywords` | Array(String) | O | 분석할 키워드 목록. 최대 10개, 중복 제거 및 앞뒤 공백 제거 |

```json
{
  "keywords": [
    "니트 가디건",
    "휴대용 선풍기",
    "캠핑 랜턴"
  ]
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `screeningId` | String | 스크리닝 결과 식별자 |
| `analyzedAt` | DateTime | 분석 완료 시각 |
| `totalCount` | Number | 실제 분석된 키워드 수 |
| `excludedCount` | Number | 최대 10개 제한으로 제외된 키워드 수 |
| `keywords` | Array | 키워드별 분석 결과 |
| `keyword` | String | 분석한 키워드 |
| `score` | Number | 종합점수(0~100) |
| `monthlySearchCount` | Number | 최근 30일 PC·모바일 합산 검색량 |
| `isSearchCountEstimated` | Boolean | 검색량이 10 미만으로 표시되어 근삿값 5를 적용했는지 여부 |
| `clickThroughRate` | Number | PC·모바일 검색량 가중 평균 클릭률(%) |
| `mobileSearchRatio` | Number | 전체 검색량 중 모바일 비중(%) |
| `competitionLevel` | String | 광고 경쟁강도 (`LOW`, `MEDIUM`, `HIGH`) |
| `competitionScore` | Number | 경쟁강도 점수(낮음 20, 중간 50, 높음 80) |
| `averageAdDepth` | Number/null | 최근 4주 PC 광고 평균 노출 깊이 |
| `searchGrowthRate` | Number/null | 작년 같은 시기 대비 검색 추이 증감률(%) |
| `shoppingGrowthRate` | Number/null | 작년 같은 시기 대비 쇼핑 클릭 추이 증감률(%). 분야 미선택 시 null |
| `categoryCode` | String/null | 선택한 쇼핑인사이트 분야 코드 |
| `categoryName` | String/null | 선택한 분야명 |
| `quadrant` | Object/null | 검색 추이·쇼핑 클릭 추이 기반 4분면 해석. 분야 미선택 시 null |
| `trendAvailable` | Boolean | 데이터랩 검색 추이 데이터 사용 가능 여부 |
| `searchTrend` | Object/null | 검색 추세선 데이터. 조회 한도 초과 등으로 사용 불가하면 null |
| `last30Days` | Array | 최근 30일 검색 추세 |
| `last12Months` | Array | 최근 12개월 검색 추세 |
| `date` | String | 일별 추세 기준 날짜 |
| `month` | String | 월별 추세 기준 월 |
| `value` | Number | 데이터랩 상대 검색 지수 |
| `notice` | String/null | 데이터랩 조회 생략 등 안내 문구 |

스크리닝은 비회원도 횟수 제한 없이 이용합니다. 비회원은 최근 결과를 브라우저 LocalStorage에서 관리하고, 로그인 회원은 JWT로 식별하여 서버에 기록합니다. 화면의 최근 스크리닝 상위 4개는 `GET /search/screenings/recent`로 조회합니다.
