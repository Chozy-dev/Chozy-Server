# 쇼핑인사이트 분야 목록 조회 API

API Path: /search/categories
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 쇼핑인사이트 분야 목록 조회 API

> 키워드 스크리닝 결과 카드에서 쇼핑 클릭 추이와 4분면 분석에 사용할 네이버 쇼핑인사이트 분야 목록을 조회합니다.
>
