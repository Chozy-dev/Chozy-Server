# 정밀분석 진행 상태 조회 API

API Path: /search/analyses/{analysisId}/status
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 정밀분석 진행 상태 조회 API

> 요청한 정밀분석의 진행 상태를 조회합니다. 분석이 완료되면 생성된 리포트 식별자를 반환합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `analysisId` | Number | O | 정밀분석 작업 식별자 |

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "정밀분석 진행 상태 조회가 완료되었습니다.",
  "data": {
    "analysisId": 1024,
    "analysisStatus": "COMPLETED",
    "currentStep": 7,
    "totalSteps": 7,
    "reportId": 2048,
    "completedAt": "2026-11-14T04:02:00+09:00",
    "errorMessage": null
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `analysisId` | Number | 정밀분석 작업 식별자 |
| `analysisStatus` | String | 분석 상태 (`PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`) |
| `currentStep` | Number | 현재 진행 단계(0~7) |
| `totalSteps` | Number | 전체 분석 단계 수 |
| `reportId` | Number/null | 완료된 정밀분석 리포트 식별자 |
| `completedAt` | DateTime/null | 분석 완료 시각 |
| `errorMessage` | String/null | 분석 실패 시 오류 내용 |
