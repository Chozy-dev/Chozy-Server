# 관심상품 등록 API

API Path: /favorites
HTTP 메서드: POST
도메인: 관심 화면
상태: 시작 전

### 관심상품 등록 API

> 정밀분석 리포트에서 분석한 상품을 관심상품으로 등록합니다. 관심중 또는 판매중 상태를 지정할 수 있으며, 저장된 리포트의 상품 정보·공급 조건·마진·점수·선택 옵션을 서버에서 가져와 저장합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `reportId` | Number | O | 관심상품으로 등록할 정밀분석 리포트 ID |
| `status` | String | O | 등록 상태 (`INTERESTED`, `SELLING`) |
- `INTERESTED`: 관심중
- `SELLING`: 판매중

```json
{
  "reportId": 2048,
  "status": "INTERESTED"
}
```

## Response Form Example

### Success — 신규 등록

```json
{
  "status": 201,
  "message": "관심상품이 등록되었습니다.",
  "data": {
    "favoriteId": 501,
    "reportId": 2048,
    "source": "DOMEME",
    "productId": "12345678",
    "productName": "캠핑 미니 랜턴 충전식",
    "status": "INTERESTED",
    "selectedOption": {
      "optionId": "OPT_RED",
      "optionName": "빨강"
    },
    "savedScore": 75,
    "savedWholesalePrice": 8000,
    "createdAt": "2026-11-17T15:00:00+09:00",
    "favoriteCount": 3,
    "favoriteLimit": 10
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `favoriteId` | Number | 등록된 관심상품의 고유 ID |
| `reportId` | Number | 등록에 사용된 정밀분석 리포트 ID |
| `source` | String | 소싱처 (`DOMEME`, `OWNERCLAN`, `MANUAL`) |
| `productId` | String/null | 소싱처 상품번호. 직접 입력 상품이면 null |
| `productName` | String | 상품명 |
| `status` | String | 관심상품 상태 (`INTERESTED`, `SELLING`) |
| `selectedOption` | Object/null | 등록할 때 선택한 판매 옵션 |
| `selectedOption.optionId` | String | 옵션 식별자 |
| `selectedOption.optionName` | String | 옵션명 |
| `savedScore` | Number/null | 등록 시점의 비용투자 적합도 점수 |
| `savedWholesalePrice` | Number | 등록 시점의 도매가(원) |
| `createdAt` | DateTime | 최초 등록 시각 |
| `favoriteCount` | Number | 등록 후 전체 관심상품 개수. 관심중·판매중 합계 |
| `favoriteLimit` | Number | 회원의 관심상품 등록 한도 |

리포트가 정상 생성된 상태여야 하며, 본인의 리포트만 등록할 수 있습니다. 등록할 상품의 정보는 요청에서 직접 받지 않고 리포트에서 조회합니다.

무료 플랜은 관심중·판매중을 합쳐 최대 10개입니다. 10개를 초과하는 신규 등록 요청은 거부합니다. 프리미엄 플랜의 한도는 50개이지만 MVP에서는 가입할 수 없습니다.

이미 등록된 상품을 다른 상태로 다시 담으면 신규 항목을 생성하지 않고 상태만 변경합니다. 이 경우 HTTP 200을 반환하며, 기존 `favoriteId`와 최초 등록 시점의 기준값을 유지합니다.

동일 상품 판단은 `[설계 제안]`으로 도매매·오너클랜 상품은 `사용자 + 소싱처 + 상품번호`, 직접 입력 상품은 `사용자 + 최초 등록 리포트 ID`를 기준으로 합니다. 소싱처가 다르면 다른 상품입니다. 동일 소싱처의 상품을 다른 옵션으로 재분석하더라도 기존 관심상품을 중복 생성하지 않으며, 기존에 저장한 선택 옵션은 유지합니다.

등록 시 선택된 옵션의 공급가·재고를 저장하고 이후 해당 옵션을 기준으로 추적합니다. 직접 입력 상품은 공급가·품절을 자동 추적하지 않습니다.

관심상품 등록은 새로운 정밀분석을 실행하지 않으며 무료 리포트 횟수도 차감하지 않습니다.

관심상품 등록 시 해당 리포트의 현재 분석 키워드를 `wishlist_items.keyword`에 저장합니다. 리포트에서 키워드를 변경했다면 변경된 키워드를 저장합니다. 이후 리포트의 분석 키워드가 변경되어도 이미 등록된 관심상품의 키워드는 변경하지 않습니다.
