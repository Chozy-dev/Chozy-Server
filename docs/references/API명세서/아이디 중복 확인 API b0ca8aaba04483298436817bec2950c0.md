# 아이디 중복 확인 API

API Path: /auth/check-login-id
HTTP 메서드: GET
도메인: 회원인증
상태: 시작 전

### 아이디 중복 확인 API

> 회원가입 시 입력한 아이디의 중복 여부를 확인합니다.
> 

### Authentication

불필요

## Request Query Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `loginId` | String | O | 중복 여부를 확인할 아이디 |

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "아이디 중복 확인이 완료되었습니다.",
  "data": {
    "loginId": "chozy123",
    "available": true
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `loginId` | String | 중복 확인한 아이디 |
| `available` | Boolean | 사용 가능 여부. `true` 사용 가능, `false` 중복 |
