# 관심상품 삭제 API

API Path: /favorites/{favoriteId}
HTTP 메서드: DELETE
도메인: 관심 화면
상태: 시작 전

### 관심상품 삭제 API

> 등록된 관심상품을 관심중·판매중 목록에서 삭제합니다. 삭제한 상품은 관심상품 개수 한도에서 제외됩니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `favoriteId` | Number | O | 삭제할 관심상품 ID |

## Request Body

없음

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "관심상품이 삭제되었습니다.",
  "data": null
}
```

## Response Data

없음

관심상품 목록과 해당 상품에 대한 개인별 추적을 해제합니다. 삭제 후 해당 상품은 관심상품 등록 한도에 포함되지 않으며, 그 상품에 대한 개인별 변동 알림도 더 이상 생성하지 않습니다.

삭제는 소싱처의 원본 상품 데이터나 서버가 공통으로 수집한 가격·품절 이력을 제거하지 않습니다. 기존 정밀분석 리포트도 삭제하지 않습니다.

삭제 전에 프론트엔드에서 확인창을 표시합니다. 존재하지 않거나 본인 소유가 아닌 관심상품은 삭제할 수 없습니다.

기존 판매 결과 기록의 보존·삭제 방식은 향후 점수 기준 개선에 사용할 데이터 정책과 개인정보 처리 기준에 맞춰 결정해야 합니다.
