# 최근 키워드 스크리닝 기록 조회 API

API Path: /search/screenings/recent
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 최근 키워드 스크리닝 기록 조회 API

> 로그인한 회원이 최근 스크리닝한 결과 중 점수 상위 4개 키워드를 조회합니다. 비회원의 최근 기록은 프론트엔드 LocalStorage에서 관리합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Query Parameters

없음

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `items` | Array | 최근 스크리닝 결과 중 점수 상위 4개 키워드. 기록이 없으면 빈 배열 |
| `items[].screeningId` | String | 해당 키워드를 분석한 스크리닝 결과 식별자 |
| `items[].keyword` | String | 분석한 키워드 |
| `items[].score` | Number | 종합점수(0~100) |
| `items[].monthlySearchCount` | Number | 최근 30일 PC·모바일 합산 검색량 |
| `items[].competitionLevel` | String | 광고 경쟁강도 (`LOW`, `MEDIUM`, `HIGH`) |
| `items[].analyzedAt` | DateTime | 스크리닝 완료 시각 |

로그인 회원의 최근 스크리닝 기록을 서버에서 조회합니다. 정밀분석 횟수에는 영향을 주지 않습니다.
