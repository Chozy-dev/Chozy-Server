# 개별 알림 읽음 처리 API

API Path: /home/notifications/{notificationId}/read
HTTP 메서드: PATCH
도메인: 홈 화면
상태: 시작 전

### 개별 알림 읽음 처리 API

> 사용자가 특정 알림을 눌렀을 때 해당 알림을 읽음 상태로 변경합니다.
> 

### Authentication

필수 (JWT)

## **Request Path Parameters**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `notificationId` | Number | O | 읽음 처리할 알림 ID |

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "알림을 읽음 처리했습니다.",
  "data": {
    "notificationId": 101,
    "isRead": true,
    "unreadCount": 1
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `notificationId` | Number | 처리 대상 알림 ID |
| `isRead` | Boolean | 처리 후 읽음 여부 |
| `unreadCount` | Number | 처리 후 남은 읽지 않은 알림 개수 |

이미 읽은 알림을 다시 요청하더라도 정상 응답하도록 구성합니다. 다른 사용자의 알림은 변경할 수 없습니다.
