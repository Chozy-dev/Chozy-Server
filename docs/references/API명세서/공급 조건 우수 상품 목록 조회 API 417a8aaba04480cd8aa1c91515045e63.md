# 공급 조건 우수 상품 목록 조회 API

API Path: /home/products/recommended
HTTP 메서드: GET
도메인: 홈 화면
상태: 시작 전

### 공급 조건 우수 상품 목록 조회 API

> 도매매·오너클랜의 전체 상품 중 공급 안정성과 공급사 신뢰도를 기준으로 산출한 점수 상위 상품을 조회합니다.
> 

### Authentication

불필요

## **Request Query Parameters**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `size` | Number | X | 조회할 상품 개수. 기본값 10 [설계 제안] |
| `source` | String | O | `DOMEME`, `OWNERCLAN`. 소싱처별 순위를 별도로 조회 |

### Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `updatedAt` | DateTime | 데이터 최종 갱신 시각 |
| `items` | Array | 추천 상품 목록 |
| `items[].rank` | Number | 순위 |
| `items[].productId` | Number | Chozy 내부 상품 ID |
| `items[].productUrl` | String | 해당 소싱처 상품 URL. 홈에서 정밀분석 요청 시 전달 |
| `items[].productName` | String | 상품명 |
| `items[].source` | String | 도매매 / 오너클랜 |
| `items[].supplyPrice` | Number | 도매가 (원) |
| `items[].supplyStabilityScore` | Number/null | 공급 안정성 점수 (0~100) |
| `items[].supplierReliabilityScore` | Number/null | 공급사 신뢰도 점수 (0~100) |
| `items[].stockoutCount90d` | Number/null | 최근 90일 품절 횟수 |
| `items[].supplierStockoutRate90d` | Number/null | 공급사의 최근 90일 품절률 (%) |
| `items[].shippingDays` | Number/null | 발송 소요일 |
| `items[].score` | Number | 홈 공급 조건 종합 점수 (0~100) |

도매매와 오너클랜은 공급사 신뢰도 산정 방식이 다르므로 두 소싱처를 하나의 순위로 합치지 않습니다. 각 요청의 `items[].rank`는 요청한 `source` 내에서의 순위입니다.
