# 리포트 추가 입력 및 재계산 API

API Path: /search/reports/{reportId}/inputs
HTTP 메서드: PATCH
도메인: 검색
상태: 시작 전

### 리포트 추가 입력 및 재계산 API

> 정밀분석 리포트에서 예상 판매가·쿠팡 카테고리·분석 키워드·판매 옵션 또는 CPC를 변경하면 해당 값을 저장하고, 영향받는 수익성·시장 진단·종합점수·투자 등급 및 관련 분석 결과를 재계산합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `reportId` | Number | O | 수정할 정밀분석 리포트 식별자 |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `expectedSellingPrice` | Number | X | 사용자가 입력한 예상 판매가(원). 100원 이상 |
| `coupangCategoryCode` | String | X | 사용자가 선택한 쿠팡 카테고리 코드 |
| `keyword` | String | X | 사용자가 변경한 리포트 분석 키워드 |
| `selectedOptionId` | String | X | 사용자가 변경한 판매 옵션 식별자 |
| `cpc` | Number/null | X | 사용자가 선택하거나 입력한 클릭당 광고비(원). 0 이상. `null`이면 저장된 CPC 초기화 |

다섯 필드 중 최소 하나는 전달해야 합니다. 전달하지 않은 필드는 기존 값을 유지합니다. `cpc=null`이면 저장된 CPC를 초기화합니다.

```json
{
  "expectedSellingPrice": 15800,
  "coupangCategoryCode": "EXAMPLE_CATEGORY",
  "keyword": "캠핑 랜턴",
  "selectedOptionId": "OPT_RED",
  "cpc": 1700
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `reportId` | Number | 수정한 정밀분석 리포트 식별자 |
| `updatedInputs` | Object | 저장된 추가 입력값 |
| `updatedInputs.expectedSellingPrice` | Number/null | 적용된 예상 판매가 |
| `updatedInputs.coupangCategoryCode` | String/null | 적용된 쿠팡 카테고리 코드 |
| `updatedInputs.keyword` | String/null | 적용된 분석 키워드 |
| `updatedInputs.selectedOptionId` | String/null | 적용된 판매 옵션 식별자 |
| `updatedInputs.cpc` | Number/null | 저장된 CPC(원). 없으면 null |
| `summary` | Object | 재계산된 종합 결과 |
| `summary.scoreStatus` | String | 계산 상태 (`CALCULATED`, `WAITING_FOR_INPUT`, `INSUFFICIENT_DATA`) |
| `summary.score` | Number/null | 재계산된 종합점수(0~100) |
| `summary.investmentGrade` | String/null | 투자 등급 (`SUITABLE`, `CONDITIONAL`, `NOT_RECOMMENDED`) |
| `summary.gradeReason` | String/null | 투자 등급 조정 사유. 조정이 없으면 null |
| `summary.supplyConditionScore` | Number/null | 공급 조건 점수 |
| `summary.marketConditionScore` | Number/null | 시장 조건 점수 |
| `summary.requiredInputs` | Array(String) | 아직 필요한 입력값 (`EXPECTED_SELLING_PRICE`, `COUPANG_CATEGORY`). 없으면 빈 배열 |
| `updatedAt` | DateTime | 재계산 완료 시각 |

분석 키워드를 변경하면 검색량·추세·경쟁도 등 해당 키워드에 의존하는 분석 항목을 다시 계산합니다. 옵션을 변경하면 해당 옵션의 원가·재고를 적용하며, 용량·수량 등 규격이 달라지는 경우 시장가도 다시 조회합니다. 기존 리포트 내 입력값·옵션 변경 및 재계산에는 무료 정밀분석 횟수를 차감하지 않습니다.

CPC를 변경하면 백엔드는 해당 값을 저장하고, 리포트의 기준 판매가·쿠팡 수수료율로 계산한 광고비 차감 전 개당 마진(`internalDiagnosis.profitability.profitPerUnit`)을 기준으로 기획서 6.4의 투자 등급 조정 규칙을 다시 적용합니다.

- CPC가 개당 마진의 50%를 **초과**하면 투자 등급을 `NOT_RECOMMENDED`로 조정합니다.
- CPC가 개당 마진의 30%를 **초과**하고 기본 투자 등급이 `SUITABLE`이면 `CONDITIONAL`로 조정합니다.
- CPC가 없으면 CPC 관련 등급 조정 규칙을 적용하지 않습니다. `cpc=0`은 유효한 입력이며 `cpc=null`로 명시적으로 초기화할 수 있습니다.
- CPC 변경은 종합점수(`summary.score`) 자체에 영향을 주지 않고 투자 등급(`summary.investmentGrade`)과 조정 사유(`summary.gradeReason`)에 반영됩니다.
- 판매가 하한·마진·CPC 등 다른 등급 조정 조건도 기획서 6.4에 정의된 **우선순위대로** 검사해 처음 적용되는 규칙의 사유를 반환합니다.
- 4단계 시뮬레이션의 판매가 슬라이더나 판매 채널 선택은 리포트의 기준 판매가·쿠팡 기준 등급을 바꾸지 않습니다. 사용자가 기준 판매가 자체를 변경하려면 `expectedSellingPrice`를 전달합니다.
- 재계산된 결과는 저장되며, 이후 `GET /search/reports/{reportId}` 호출 시 `investmentSimulation.cpc`, `summary.investmentGrade`, `summary.gradeReason`에 반영됩니다.
- CPC 변경과 등급 재계산은 무료 정밀분석 횟수를 차감하지 않습니다.
