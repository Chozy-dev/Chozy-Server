# 네이버·쿠팡 비교 조회 API

API Path: /home/keywords/compare
HTTP 메서드: GET
도메인: 홈 화면
상태: 시작 전

### ****네이버·쿠팡 비교 조회 API

> 선택한 네이버 시즌 테마의 상위 10개 키워드가 수집된 쿠팡 베스트 상품명에 포함되어 있는지 비교합니다.
> 

### Authentication

불필요

## **Request Query Parameters**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `themeCode` | Number | X | 네이버 시즌 테마 코드. 기본 테마 사용 가능 |

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "네이버·쿠팡 비교 조회가 완료되었습니다.",
  "data": {
    "updatedAt": "2026-11-14T03:00:00+09:00",
    "themeCode": 6,
    "themeName": "난방/방한",
    "matchedKeywords": [
      {
        "keyword": "전기요",
        "monthlySearchCount": 180000,
        "growthRate": 64.2,
        "matchedProductCount": 3
      }
    ],
    "unmatchedKeywords": [
      {
        "keyword": "문풍지",
        "monthlySearchCount": 55000,
        "growthRate": 12.5,
        "matchedProductCount": 0
      }
    ],
    "notice": "쿠팡은 서버가 수집한 베스트 카테고리만 비교한 결과입니다."
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `updatedAt` | DateTime | 비교 결과의 최종 갱신 시각 |
| `themeCode` | Number | 실제 비교에 사용한 네이버 시즌 테마 코드 |
| `themeName` | String | 테마 이름 |
| `matchedKeywords` | Array | 수집된 쿠팡 베스트 상품명에 포함되는 키워드 목록 |
| `unmatchedKeywords` | Array | 수집된 쿠팡 베스트 상품명에 포함되지 않는 키워드 목록 |
| `matchedKeywords[].keyword` | String | 네이버 키워드 |
| `matchedKeywords[].monthlySearchCount` | Number | PC·모바일 월간 검색수 합계 |
| `matchedKeywords[].growthRate` | Number/null | 최근 4주 평균을 직전 4주 평균과 비교한 검색 추세 상승률(%) |
| `matchedKeywords[].matchedProductCount` | Number | 해당 키워드가 포함된 쿠팡 베스트 상품 개수 |
| `unmatchedKeywords[].keyword` | String | 네이버 키워드 |
| `unmatchedKeywords[].monthlySearchCount` | Number | PC·모바일 월간 검색수 합계 |
| `unmatchedKeywords[].growthRate` | Number/null | 최근 4주 평균을 직전 4주 평균과 비교한 검색 추세 상승률(%) |
| `unmatchedKeywords[].matchedProductCount` | Number | 일치 상품 개수. 항상 0 |
| `notice` | String | 비교 범위 안내 문구 |
