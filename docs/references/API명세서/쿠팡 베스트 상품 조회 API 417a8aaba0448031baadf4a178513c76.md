# 쿠팡 베스트 상품 조회 API

API Path: /home/keywords/coupang
HTTP 메서드: GET
도메인: 홈 화면
상태: 시작 전

### 쿠팡 베스트 상품 조회 API

> 쿠팡 파트너스 API에서 매일 수집한 카테고리별 베스트 상품 목록을 조회합니다. 상품의 전날 대비 순위 변동을 함께 제공합니다.
> 

### Authentication

불필요

## **Request Query Parameters**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `categoryId` | Number | X | 쿠팡 카테고리 ID. 미입력 시 기본 카테고리  |

### Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `updatedAt` | DateTime | 최종 수집 시각 |
| `categories` | Array | 조회 가능한 카테고리 목록 |
| `categories[].categoryId` | Number | 쿠팡 카테고리 ID |
| `categories[].categoryName` | String | 카테고리 이름 |
| `selectedCategoryId` | Number | 현재 선택된 카테고리 |
| `items` | Array | 베스트 상품 목록 |
| `items[].rank` | Number | 현재 순위 |
| `items[].productId` | Number | 쿠팡 상품 ID |
| `items[].productName` | String | 상품명 |
| `items[].price` | Number | 상품 가격 (원) |
| `items[].isRocketDelivery` | Boolean | 로켓배송 여부 |
| `items[].previousRank` | Number/null | 전날 순위 |
| `items[].rankChange` | Number/null | 전날 대비 상승 순위 |
| `items[].rankStatus` | String | `UP`, `DOWN`, `SAME`, `NEW` |
