# 관심상품 상세 조회 API

API Path: /favorites/{favoriteId}
HTTP 메서드: GET
도메인: 관심 화면
상태: 시작 전

### 관심상품 상세 조회 API

> 선택한 관심상품의 핵심 정보, 공급가 추이, 최근 90일 품절 빈도, 점수 변화, 공급사 정보, 판매 결과 및 도매몰 이동 정보를 조회합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `favoriteId` | Number | O | 조회할 관심상품 고유 ID |

## Request Query Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `periodDays` | Number | X | 공급가 추이 조회 기간 (`7`, `14`, `30`, `90`). 기본값 30 |

### 공급사 및 판매 정보

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `supplier` | Object/null | 공급사 정보. 직접 입력 상품은 null |
| `supplier.supplierName` | String | 공급사명 |
| `supplier.evaluationBasis` | String | 신뢰도 산정 기준 (`REVIEW_SATISFACTION`, `SUPPLIER_STOCKOUT_RATE`) |
| `supplier.reliabilityScore` | Number/null | 공급사 신뢰도 점수 |
| `supplier.reviewSatisfactionRate` | Number/null | 후기 만족도(%). 도매매 기준 |
| `supplier.reviewCount` | Number/null | 후기 수 |
| `supplier.supplierStockoutRate90d` | Number/null | 공급사 전체 상품 기준 90일 품절률(%). 오너클랜 기준 |
| `supplier.shippingDays` | Number/null | 평균 발송 소요일 |
| `supplier.sellerGrade` | Number/null | 공급사 판매등급 |
| `salesResult` | Object/null | 가장 최근 판매 결과. 기록이 없으면 null |
| `salesResult.result` | String | 판매 결과 (`GOOD`, `AVERAGE`, `POOR`, `NOT_LISTED`) |
| `salesResult.recordedAt` | DateTime | 판매 결과 기록 시각 |
| `purchaseLink` | Object | 도매몰 바로가기 |
| `purchaseLink.url` | String/null | 상품 URL. 직접 입력 상품이면 null |
| `purchaseLink.isAffiliateLink` | Boolean | 제휴 링크 여부 |
| `createdAt` | DateTime | 최초 등록 시각 |
| `updatedAt` | DateTime | 상세 추적 정보 마지막 갱신 시각 |

공급가는 도매매·오너클랜 전 상품 수집 데이터를 이용하므로 관심상품 등록일보다 이전의 이력도 최근 90일 범위에서 조회할 수 있습니다. 품절 빈도는 `periodDays`와 관계없이 최근 90일로 고정합니다. 현재 품절 중인 구간은 `endedAt=null`로 반환하며, `durationDays`에는 현재 집계 기준일까지의 품절 일수를 반영합니다.

공급 조건과 마진은 매일 갱신합니다. 쿠팡 시장가는 주 1회 갱신을 목표로 하며, 상세 조회 시 마지막 시장가 조회가 24시간보다 오래되었으면 해당 상품의 갱신을 시도합니다. 외부 API 한도 때문에 즉시 갱신하지 못한 경우 기존 저장값을 반환하고 `marketPriceRefreshStatus=DEFERRED`로 표시합니다. 시장 조건 역시 API 예산 내에서 주기적으로 갱신하며 각각의 기준 시각을 반환합니다.

옵션별 가격이 다른 상품은 관심상품 등록 시 선택한 옵션을 기준으로 공급가·품절을 추적합니다. 다른 옵션의 품절 정보는 상품 데이터에 존재하는 경우에만 표시하며, 선택 옵션의 품절 알림 기준에는 포함하지 않습니다.

`product.otherOptionStockouts`에는 선택한 옵션을 제외하고 현재 품절된 옵션만 반환합니다. 다른 옵션의 품절 상태를 확인할 수 있고 품절된 옵션이 없다면 빈 배열(`[]`)을 반환하며, 옵션 정보가 없거나 확인할 수 없으면 `null`을 반환합니다. 프론트엔드는 해당 배열에 값이 있을 때 다른 옵션의 품절 정보를 관심상품 상세 화면에 표시합니다. 다른 옵션의 품절은 선택한 옵션의 공급가·품절 알림이나 점수 계산에 영향을 주지 않습니다.

직접 입력 상품은 `priceHistory`, `stockoutHistory`, `supplier`를 null로 반환합니다. 시장 조건만 주기적으로 갱신합니다.

`purchaseLink.isAffiliateLink=true`이면 프론트엔드는 도매몰 이동 버튼 아래에 제휴 수수료 안내를 표시하고 링크에 `rel="sponsored"`를 적용합니다. 직접 입력 상품은 도매몰 이동 버튼을 숨깁니다.

상세 화면에서 기존 리포트를 열 때는 `reportId`로 `GET /search/reports/{reportId}`를 호출할 수 있으며, 조회만으로 무료 정밀분석 횟수는 차감되지 않습니다.
