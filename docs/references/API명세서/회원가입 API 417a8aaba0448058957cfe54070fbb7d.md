# 회원가입 API

API Path: /auth/signup
HTTP 메서드: POST
도메인: 회원인증
상태: 시작 전

### 회원가입 API

> 아이디·비밀번호·닉네임·이메일·필수 약관 동의 여부를 검증하고 신규 회원을 등록합니다.
> 

### Authentication

불필요

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `loginId` | String | O | 로그인에 사용할 아이디 |
| `password` | String | O | 비밀번호 |
| `nickname` | String | O | 사용자 닉네임 |
| `email` | String | O | 이메일 주소 |
| `termsAgreed` | Boolean | O | 서비스 이용약관 동의 여부. `true` 필수 |
| `privacyAgreed` | Boolean | O | 개인정보 수집·이용 동의 여부. `true` 필수 |

```json
{
  "loginId": "chozy123",
  "password": "ExamplePassword123!",
  "nickname": "초보셀러",
  "email": "chozy123@example.com",
  "termsAgreed": true,
  "privacyAgreed": true
}
```

## Response Form Example

### Success

```json
{
  "status": 201,
  "message": "회원가입이 완료되었습니다.",
  "data": {
    "userId": 1024,
    "loginId": "chozy123",
    "nickname": "초보셀러",
    "email": "chozy123@example.com",
    "createdAt": "2026-11-14T04:00:00+09:00"
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `userId` | Number | 생성된 회원 식별자 |
| `loginId` | String | 회원 아이디 |
| `nickname` | String | 사용자 닉네임 |
| `email` | String | 이메일 주소 |
| `createdAt` | DateTime | 회원가입 완료 시각 |
