# 네이버 시즌 키워드 조회 API

API Path: /home/keywords/naver
HTTP 메서드: GET
도메인: 홈 화면
상태: 시작 전

### 네이버 시즌 키워드 조회 API

> 선택한 시즌 테마의 네이버 키워드 상위 10개를 조회합니다. 월간 검색수 기준 내림차순으로 정렬하고, 각 키워드의 최근 검색량 상승률을 함께 반환합니다.
> 

### Authentication

불필요

## **Request Query Parameters**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `themeCode` | Number | X | 시즌 테마 코드. 미입력 시 서버 기본 테마  |

### Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `updatedAt` | DateTime | 데이터 최종 갱신 시각 |
| `themes` | Array | 이번 달 제공하는 시즌 테마 목록 |
| `themes[].themeCode` | Number | 네이버 시즌 테마 코드. 비교 조회 API와 동일한 값 사용 |
| `themes[].themeName` | String | 시즌 테마 이름 |
| `selectedThemeCode` | Number | 실제 조회에 사용한 시즌 테마 코드 |
| `items` | Array | 월간 검색수 기준 상위 키워드 목록. 최대 10개 |
| `items[].rank` | Number | 월간 검색수 기준 순위 |
| `items[].keyword` | String | 키워드 |
| `items[].monthlySearchCount` | Number | PC·모바일 월간 검색수 합계 |
| `items[].growthRate` | Number/null | `(최근 4주 검색 추세 평균 ÷ 직전 4주 검색 추세 평균 - 1) × 100`. 데이터 부족 또는 분모가 0이면 null |
