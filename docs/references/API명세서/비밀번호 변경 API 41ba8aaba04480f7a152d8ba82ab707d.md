# 비밀번호 변경 API

API Path: /my/password
HTTP 메서드: PATCH
도메인: 마이 화면
상태: 시작 전

### 비밀번호 변경 API

> 로그인한 사용자의 현재 비밀번호를 확인한 뒤 새로운 비밀번호로 변경합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `currentPassword` | String | O | 현재 사용 중인 비밀번호 |
| `newPassword` | String | O | 변경할 새로운 비밀번호 |

```json
{
  "currentPassword": "ExamplePassword123!",
  "newPassword": "NewExamplePassword456!"
}
```

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "비밀번호가 변경되었습니다. 다시 로그인해 주세요.",
  "data": null
}
```

## Response Data

없음

현재 비밀번호가 일치해야 변경할 수 있습니다. 새로운 비밀번호는 회원가입 시 사용하는 비밀번호 검증 정책과 동일한 기준을 적용합니다.

현재 비밀번호와 새로운 비밀번호가 같으면 변경을 거부합니다.

새 비밀번호는 평문으로 저장하지 않고 안전한 단방향 비밀번호 해시 알고리즘으로 저장합니다.

비밀번호 변경 성공 시 백엔드는 기존 Refresh Token을 무효화하고, 기존 Access Token도 더 이상 인증에 사용할 수 없도록 처리합니다.

프론트엔드는 비밀번호 변경 성공 응답을 받으면 저장된 토큰을 삭제하고 로그인 화면으로 이동합니다.

현재 비밀번호가 일치하지 않거나 새로운 비밀번호가 정책을 충족하지 못하면 변경하지 않습니다. 비밀번호는 응답에 포함하지 않습니다.
