# 무료-정밀분석 사용량 조회 API

API Path: /home/report-usage
HTTP 메서드: GET
도메인: 홈 화면
상태: 시작 전

### **무료-정밀분석 사용량 조회 API**

> 로그인한 무료 회원의 정밀분석 사용량과 월간 기본 한도를 조회합니다. MVP 기준 무료 회원은 매월 3회이며, 매월 1일 0시(한국 시간)에 사용량이 초기화됩니다.
> 

### Authentication

필수 (JWT)

## **Request Query Parameters**

없음

## Response Form Example

#### Success — 로그인한 무료 회원

```json
{
  "status": 200,
  "message": "정밀분석 사용량 조회가 완료되었습니다.",
  "data": {
    "isLoggedIn": true,
    "plan": "FREE",
    "period": "2026-11",
    "periodType": "MONTH",
    "usedCount": 1,
    "limitCount": 3,
    "remainingCount": 2
  }
}
```

### Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `plan` | String | MVP에서는 `FREE` |
| `periodType` | String | MVP에서는 `MONTH` |
| `period` | String | `YYYY-MM`. 한국 시간 기준, 매월 1일 0시에 초기화 |
| `usedCount` | Number | 해당 기간에 기본 한도에서 사용한 횟수 |
| `limitCount` | Number | MVP 무료 회원 기본값 3 (서버 설정값으로 관리) |
| `remainingCount` | Number | 남은 기본 사용 횟수. 최솟값 0 |

분석이 완료되어 리포트가 정상 생성된 경우에만 1회 차감합니다. 
실패한 분석, 기존 리포트 조회, 리포트 내 옵션·입력값 변경은 차감하지 않습니다. 
프리미엄 요금제는 MVP에서 제외하며 한도는 추후 확정합니다.
데이터랩 한도를 100% 소진한 경우에는 트렌드·지속성을 제외하고 리포트를 생성하되, 무료 횟수는 차감하지 않습니다.
