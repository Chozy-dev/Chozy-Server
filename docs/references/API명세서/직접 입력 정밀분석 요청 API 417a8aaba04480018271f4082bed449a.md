# 직접 입력 정밀분석 요청 API

API Path: /search/analyses/manual
HTTP 메서드: POST
도메인: 검색
상태: 시작 전

### 직접 입력 정밀분석 요청 API

> 공식 API를 지원하지 않는 도매몰의 상품 정보를 직접 입력받아 수익성·시장 트렌드·경쟁강도·판매전략·광고비 시뮬레이션 분석을 요청합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `productName` | String | O | 상품명 |
| `wholesalePrice` | Number | O | 도매가(원). 0 초과 |
| `shippingFee` | Number | O | 배송비(원). 무료배송이면 0 |
| `hasPricePolicy` | Boolean | O | 가격 준수 정책 존재 여부 |
| `minimumSellingPrice` | Number | X | 최종준수가(원). 가격 준수 정책이 있는 경우 필수 |
| `keyword` | String | X | 스크리닝에서 선택한 분석 키워드 |

```json
{
  "productName": "캠핑 미니 랜턴 충전식",
  "wholesalePrice": 8000,
  "shippingFee": 3000,
  "hasPricePolicy": true,
  "minimumSellingPrice": 15000,
  "keyword": "캠핑 랜턴"
}
```

## Response Form Example

### Success

```json
{
  "status": 202,
  "message": "직접 입력 정밀분석 요청이 접수되었습니다.",
  "data": {
    "analysisId": 1025,
    "reportId": null,
    "source": "MANUAL",
    "productName": "캠핑 미니 랜턴 충전식",
    "keyword": "캠핑 랜턴",
    "analysisStatus": "PROCESSING",
    "requestedAt": "2026-11-14T04:05:00+09:00",
    "availableFeatures": [
      "PROFITABILITY",
      "MARKET_TREND",
      "COMPETITION",
      "SALES_STRATEGY",
      "AD_SIMULATION"
    ],
    "unavailableFeatures": [
      "SUPPLY_STABILITY",
      "SUPPLIER_RELIABILITY"
    ]
  }
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `analysisId` | Number | 정밀분석 작업 식별자 |
| `reportId` | Number/null | 생성된 리포트 식별자. 분석 완료 전 null |
| `source` | String | 분석 유형 (`MANUAL`) |
| `productName` | String | 분석 상품명 |
| `keyword` | String/null | 분석에 우선 사용할 키워드 |
| `analysisStatus` | String | 분석 상태 (`PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`) |
| `requestedAt` | DateTime | 분석 요청 시각 |
| `availableFeatures` | Array(String) | 직접 입력으로 제공 가능한 분석 항목 |
| `unavailableFeatures` | Array(String) | 데이터 부족으로 제공하지 않는 분석 항목 |

분석이 성공적으로 완료되어 리포트가 생성될 때만 무료 횟수 1회를 차감하며, 분석 실패 시에는 차감하지 않습니다.
 기존 리포트 조회는 차감하지 않습니다. 
`[지금 데이터로 다시 분석]`은 저장된 직접 입력값으로 이 API에 새 요청을 보내며, 새 리포트 생성에 성공하면 1회 차감합니다.
데이터랩 한도를 100% 소진한 경우에는 트렌드·지속성을 제외하고 리포트를 생성하되, 무료 횟수는 차감하지 않습니다
