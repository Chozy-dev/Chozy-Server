# 알림 설정 조회 API

API Path: /my/notification-settings
HTTP 메서드: GET
도메인: 마이 화면
상태: 시작 전

### 알림 설정 조회 API

> 로그인한 사용자의 관심상품 변동 및 검색량 급상승 알림 설정을 조회합니다. 알림 종류별 활성화 여부, 이메일 알림 사용 여부, 공급가·점수·검색량 변동 기준을 반환합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Query Parameters

없음

## Response Form Example

### Success

```json
{
  "status": 200,
  "message": "알림 설정 조회가 완료되었습니다.",
  "data": {
    "inAppEnabled": true,
    "emailEnabled": true,
    "pushStatus": "COMING_SOON",
    "eventTypes": {
      "supplyPriceEnabled": true,
      "scoreChangeEnabled": true,
      "stockOutEnabled": true,
      "restockEnabled": true,
      "searchVolumeEnabled": true
    },
    "thresholds": {
      "supplyPriceChangePercent": 10,

```

## Response Data

### 알림 수신 방식

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `inAppEnabled` | Boolean | 앱 안 알림 활성화 상태. MVP에서는 항상 true |
| `emailEnabled` | Boolean | 이메일 알림 활성화 여부 |
| `pushStatus` | String | 푸시 알림 제공 상태. MVP에서는 `COMING_SOON` |

### 알림 종류 (`eventTypes`)

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `eventTypes` | Object | 알림 종류별 활성화 여부 |
| `eventTypes.supplyPriceEnabled` | Boolean | 공급가 변동 알림 |
| `eventTypes.scoreChangeEnabled` | Boolean | 비용투자 적합도 점수 변화 알림 |
| `eventTypes.stockOutEnabled` | Boolean | 품절 알림 |
| `eventTypes.restockEnabled` | Boolean | 재입고 알림 |
| `eventTypes.searchVolumeEnabled` | Boolean | 검색량 급상승 알림 |

### 알림 기준 (`thresholds`)

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `thresholds` | Object | 알림 발생 기준값 |
| `thresholds.supplyPriceChangePercent` | Number | 공급가 변동률 기준(%). 기본값 10 |
| `thresholds.scoreChangePoints` | Number | 점수 변동폭 기준(점). `5`, `10`, `15` |
| `thresholds.searchVolumeIncreasePercent` | Number | 전주 대비 검색량 증가율 기준(%). `30`, `50`, `100` |
| `updatedAt` | DateTime/null | 사용자가 알림 설정을 마지막으로 변경한 시각 |

### 알림 종류별 기준

| 알림 종류 | 발생 기준 | 확인 주기 |
| --- | --- | --- |
| 공급가 변동 | 설정한 변동률 이상 | 매일 |
| 점수 변화 | 설정한 변동폭 이상 | 공급 조건은 매일, 시장 조건은 주기적 갱신 시 |
| 품절 | 품절 발생 | 매일 |
| 재입고 | 품절 상태에서 재입고 | 매일 |
| 검색량 급상승 | 전주 대비 설정한 증가율 이상 | 주 1회 |

공급가 변동은 관심상품에 등록된 소싱처와 선택 옵션의 공급가를 기준으로 판단합니다.

재고 수량 변화 자체에 대한 알림은 제공하지 않습니다. 품절과 재입고만 감지합니다.

점수 변동 알림은 기본 5점 이상이며, 5·10·15점 중 선택할 수 있습니다. 검색량 급상승 알림은 30·50·100% 중 선택할 수 있습니다.

공급가 변동 알림의 기본 기준은 10%입니다. 구체적인 설정 범위는 기획서에 확정되어 있지 않으므로, 변경 API에서 정한 입력 범위를 사용합니다.

앱 안 알림은 항상 활성화되며, 이메일 알림은 사용자가 켜거나 끌 수 있습니다. 푸시 알림은 MVP에서 제공하지 않습니다.

알림 종류별 활성화 여부는 해당 유형의 개인 변동 알림에 적용합니다. 시스템 알림 및 서비스 공지는 별도로 처리합니다.

최초 가입 시 별도 설정 기록이 없으면 기본 설정을 반환합니다. 이메일 알림은 기본 활성화(가안)이며, 개별 알림 종류는 모두 활성화를 초기값으로 사용합니다.

검색량 급상승 알림은 관심상품에 등록된 상품의 분석 키워드(`wishlist_items.keyword`)만 추적합니다. `INTERESTED`(관심중)와 `SELLING`(판매중) 상태를 모두 포함하며, 스크리닝 기록의 키워드나 전체 키워드는 추적하지 않습니다.
