# 상품 URL 판별 API

API Path: /search/products/resolve-url
HTTP 메서드: POST
도메인: 검색
상태: 시작 전

### 상품 URL 판별 API

> 입력한 상품 URL의 소싱처와 상품번호를 확인합니다. 도매꾹 상품은 같은 상품번호의 도매매 위탁 상품 존재 여부를 확인하며, 지원하지 않는 사이트는 직접 입력을 안내합니다.
> 
> 
> 자동 분석이 가능한 상품은 옵션 목록도 함께 반환합니다. 옵션마다 가격이 다르면 정밀분석 전에 옵션을 선택하도록 합니다.
> 

### Authentication

불필요

## Request Body

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `url` | String | O | 분석할 도매몰 상품 URL |

```json
{
  "url": "https://domeggook.com/12345678"
}
```

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `source` | String | 원본 상품 소싱처 (`DOMEME`, `OWNERCLAN`, `DOMEGGOOK`, `OTHER`) |
| `productId` | String/null | URL에서 추출한 상품번호 |
| `supported` | Boolean | 자동 분석 지원 여부 |
| `analysisType` | String/null | 실제 분석에 사용할 소싱처 형식 (`DOMEME`, `OWNERCLAN`) |
| `converted` | Boolean | 도매꾹 상품을 도매매 상품으로 전환했는지 여부 |
| `originalUrl` | String | 사용자가 입력한 URL |
| `resolvedUrl` | String/null | 실제 분석에 사용할 상품 URL |
| `manualInputRequired` | Boolean | 직접 입력 안내 필요 여부 |
| `notice` | String/null | 링크 판별 및 전환 안내 문구 |
| `optionSelectionRequired` | Boolean | 옵션별 가격이 달라 분석 전에 옵션 선택이 필요한지 여부 |
| `options` | Array | 판매 옵션 목록. 옵션이 없거나 자동 분석이 불가능하면 빈 배열 |
| `options[].optionId` | String | 정밀분석 요청에 전달할 옵션 식별자 |
| `options[].optionName` | String | 화면에 표시할 옵션명 |
| `options[].price` | Number | 해당 옵션의 최종 도매가(원) |
| `options[].stockQuantity` | Number/null | 옵션별 재고 수량. 확인할 수 없으면 null |

옵션별 가격이 모두 같거나 옵션이 없는 경우 `optionSelectionRequired`는 `false`입니다.

`optionSelectionRequired`가 `true`이면 프론트에서 옵션 선택 화면을 표시하고, 선택한 `optionId`를 상품 URL 정밀분석 요청 API(`POST /search/analyses/url`)의 `selectedOptionId`로 전달합니다.

도매꾹 링크는 도매매 상품으로 전환한 뒤 해당 상품의 옵션을 반환합니다.

도매매의 `selectOpt` 상세 구조와 옵션 가격이 최종가인지 추가금인지는 기획서상 실측 확인 전이므로, 구현 시 확인한 구조를 정규화하여 `price`에 최종 도매가를 반환합니다.
