# 쿠팡 카테고리 목록 조회 API

API Path: /search/coupang-categories
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 쿠팡 카테고리 목록 조회 API

> 정밀분석 리포트에서 쿠팡 카테고리를 자동으로 결정하지 못했을 때, 사용자가 직접 선택할 수 있는 쿠팡 대분류 목록과 기본 수수료율을 조회합니다.
>

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `categories` | Array | 선택 가능한 쿠팡 대분류 15개 목록 |
| `categoryCode` | String | 카테고리 식별 코드 |
| `categoryName` | String | 쿠팡 대분류 이름 |
| `feeRate` | Number | 해당 대분류의 기본 판매 수수료율(%). 부가세 10% 포함 |

## 처리 규칙

- 쿠팡 카테고리를 자동으로 결정하지 못해 `COUPANG_CATEGORY` 입력이 필요한 경우, 프론트는 이 API로 선택 가능한 목록을 조회합니다.
- 사용자가 카테고리를 선택하면 해당 `categoryCode`를 기존 **리포트 추가 입력 및 재계산 API**의 `coupangCategoryCode`로 전달합니다.
- 사용자가 대분류만 선택한 경우 해당 대분류의 기본 수수료율을 적용하고, "중분류에 따라 실제 수수료율이 달라질 수 있어요"라고 안내합니다.
- 자동으로 카테고리 전체 경로가 결정된 경우에는 기획서 부록 A의 중·소분류 예외 수수료율을 우선 적용합니다.
- `categoryCode`의 영문 값은 Chozy 내부에서 사용하는 대분류 식별자로 정한 **[설계 제안]**이며, 쿠팡 Wing API의 실제 카테고리 ID가 아닙니다. 백엔드는 이 내부 코드와 기본 수수료율의 매핑을 관리합니다.
- 카테고리 수수료율은 기획서 부록 A를 기준으로 하며, 서버에서 관리합니다.
