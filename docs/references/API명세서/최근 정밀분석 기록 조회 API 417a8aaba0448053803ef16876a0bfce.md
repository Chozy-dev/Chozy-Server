# 최근 정밀분석 기록 조회 API

API Path: /search/analyses/recent
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 최근 정밀분석 기록 조회 API

> 로그인한 사용자의 최근 정밀분석 기록을 조회합니다. URL 분석과 직접 입력 분석 기록을 함께 반환합니다.
> 

### Authentication

필수(JWT)

## Request Header

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `Authorization` | String | O | `Bearer {accessToken}` |

## Request Query Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `page` | Number | X | 페이지 번호. 기본값 0 |
| `size` | Number | X | 페이지당 조회 개수. 기본값 10 |

## Response Data

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `analyses` | Array | 최근 정밀분석 기록 목록 |
| `analysisId` | Number | 정밀분석 작업 식별자 |
| `reportId` | Number/null | 정밀분석 리포트 식별자 |
| `analysisType` | String | 분석 입력 방식 (`URL`, `MANUAL`) |
| `source` | String | 소싱처 (`DOMEME`, `OWNERCLAN`, `MANUAL`) |
| `productId` | String/null | 소싱처 상품번호 |
| `productName` | String | 상품명 |
| `productImageUrl` | String/null | 상품 대표 이미지 URL |
| `keyword` | String/null | 분석 키워드 |
| `score` | Number/null | 비용 투자 적합도 점수(0~100). 계산 대기 시 null |
| `investmentGrade` | String/null | 투자 등급 (`SUITABLE`, `CONDITIONAL`, `NOT_RECOMMENDED`). 계산 대기 시 null |
| `analysisStatus` | String | 분석 상태 |
| `analyzedAt` | DateTime | 분석 완료 시각 |
| `page` | Number | 현재 페이지 번호 |
| `size` | Number | 페이지당 조회 개수 |
| `totalElements` | Number | 전체 분석 기록 수 |
| `totalPages` | Number | 전체 페이지 수 |
| `hasNext` | Boolean | 다음 페이지 존재 여부 |
