# 리포트 상세 조회 API

API Path: /search/reports/{reportId}
HTTP 메서드: GET
도메인: 검색
상태: 시작 전

### 리포트 상세 조회 API

> 분석이 완료된 정밀분석 리포트를 조회합니다. 종합점수·투자 등급과 1단계 내부 진단, 2단계 외부 진단, 3단계 비용 투자 전략, 4단계 비용 투자 시뮬레이션 결과를 함께 반환합니다. 분석 완료 후 또는 최근 분석 기록에서 리포트를 선택했을 때 호출합니다. 기존 리포트 조회는 분석 횟수를 차감하지 않습니다.
> 

### Authentication

필수(JWT)

## Request Path Parameters

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `reportId` | Number | O | 조회할 정밀분석 리포트 식별자 |

## Response Data

### 기본 정보

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `reportId` | Number | 정밀분석 리포트 식별자 |
| `analysisId` | Number | 정밀분석 작업 식별자 |
| `analysisType` | String | 분석 입력 방식 (`URL`, `MANUAL`) |
| `source` | String | 실제 분석 소싱처 (`DOMEME`, `OWNERCLAN`, `MANUAL`) |
| `analyzedAt` | DateTime | 분석 완료 시각. 한국 시간 기준 |
| `product` | Object | 상품·공급사 기본 정보와 공급 조건 |
| `summary` | Object | 종합점수·투자 등급·분석 요약 |
| `internalDiagnosis` | Object | 1단계 내부 진단 |
| `externalDiagnosis` | Object | 2단계 외부 진단 |
| `investmentStrategy` | Object | 3단계 비용 투자 전략 |
| `investmentSimulation` | Object | 4단계 비용 투자 시뮬레이션의 초기 계산값 |
| `unavailableFeatures` | Array(String) | 제공하지 못하는 분석 항목. 없으면 빈 배열 |
| `notices` | Array(String) | 리포트 전체 안내. 없으면 빈 배열 |

### 공급 조건 상세 정보 (`product.supplyConditions`)

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `returnShippingFee` | Number/null | 도매매 반품배송비(원) |
| `doubleReturnFeeForFreeShipping` | Boolean/null | 도매매 무료배송 주문에서 반품비가 2배 적용되는지 여부 |
| `remoteAreaAdditionalShippingFee` | Number/null | 도매매 제주·도서산간 추가배송비(원) |
| `imageReuseAllowed` | Boolean/null | 도매매 상세 이미지 재사용 가능 여부 |
| `exclusiveSale` | Boolean/null | 도매매 단독판매 여부 |
| `sellerNotice` | String/null | 도매매 판매자 공지 |
| `returnAllowed` | Boolean/null | 오너클랜 반품 가능 여부 |
| `returnRestrictionReason` | String/null | 오너클랜 반품 불가 사유 |
| `maxBundleShippingQuantity` | Number/null | 오너클랜 묶음배송 최대 수량 |
| `shippingCutoffTime` | String/null | 오너클랜 배송 마감 시각. 확인 가능한 경우 `HH:mm` |
| `taxExempt` | Boolean/null | 오너클랜 면세 상품 여부 |
| `supplierNotice` | String/null | 오너클랜 공급사 알림 |

도매매 상품은 도매매 전용 항목을, 오너클랜 상품은 오너클랜 전용 항목을 채웁니다. 다른 소싱처 전용 항목이나 외부 API에서 확인할 수 없는 항목은 null로 반환합니다.

직접 입력 분석은 공급 조건을 조회할 수 없으므로 `supplyConditions` 전체를 null로 반환합니다.

오너클랜의 제주·도서산간 추가배송비는 상품 조회 API에서 확인할 수 없으므로 주문 단계에서 확인해야 한다는 안내를 표시합니다.

이 상세 공급 조건은 화면 표시용이며, 기존 종합점수 계산 로직과 가중치는 변경하지 않습니다.

### 1단계 내부 진단 (`internalDiagnosis`)

| 이름 | 타입 | 설명 |
| --- | --- | --- |
| `profitability` | Object | 수익성 분석 |
| `profitability.score` | Number/null | 수익성 점수 |
| `profitability.wholesalePrice` | Number | 도매가(원) |
| `profitability.shippingFee` | Number | 개당 배송비(원) |

조회 시 외부 API를 다시 호출하거나 정밀분석 사용 횟수를 차감하지 않고 저장된 분석 결과를 반환합니다. 본인의 리포트만 조회할 수 있습니다.

직접 입력 분석에서는 `supplyStability`와 `supplierReliability`를 null로 반환하고, `unavailableFeatures`에 `SUPPLY_STABILITY`, `SUPPLIER_RELIABILITY`를 포함합니다. 제조사 정보가 없으면 상표 확인은 공급사 확인 안내로 반환합니다.

데이터가 없는 항목은 0으로 대체하지 않고 null로 반환합니다. 목록이 없으면 빈 배열로 반환합니다. 종합점수는 결측 항목의 가중치 재분배와 기획서의 점수·등급 제한 규칙을 적용합니다.

분석 작업이 완료되었어도 시장가·카테고리 등이 부족하면 리포트는 정상 조회됩니다. 이 경우 `summary.scoreStatus`와 `requiredInputs`로 계산 대기 상태 및 필요한 입력을 안내합니다.

4단계는 화면 진입 시 필요한 초기값을 반환합니다. 사용자가 변경하는 판매가 슬라이더·목표 마진율·수수료·판매량·비용에 따른 단순 시뮬레이션 계산과 CPC를 활용한 예상 광고비 계산은 프론트에서 수행하며, 계산 채널을 바꿔도 리포트 종합점수는 쿠팡 기준으로 유지합니다. 단, **CPC 변경에 따른 투자 등급 조정은 백엔드에서 수행**합니다. 프론트는 CPC 변경 시 `PATCH /search/reports/{reportId}/inputs`에 `cpc`를 전달하고, 응답의 `summary.investmentGrade`·`summary.gradeReason`을 화면에 반영합니다. 백엔드는 저장된 CPC와 리포트의 기준 판매가·쿠팡 수수료율로 계산한 개당 마진을 사용해 기획서 6.4의 투자 등급 조정 규칙을 적용합니다. CPC 변경은 종합점수(`summary.score`)에는 영향을 주지 않습니다.

`isAffiliateLink`가 `true`이면 프론트엔드는 도매몰 이동 버튼 아래에 제휴 수수료 안내를 표시하고 링크에 `rel="sponsored"`를 적용합니다. 오너클랜은 제휴 프로그램이 확인되기 전까지 일반 상품 링크를 제공하며 `isAffiliateLink=false`입니다. 직접 입력 분석은 `purchaseUrl=null`입니다. 옵션을 바꾸려면 `POST /search/products/resolve-url`에 기존 상품 URL을 전달해 선택지를 확인하고 `PATCH /search/reports/{reportId}/inputs`에 `selectedOptionId`를 전달합니다. 분석 키워드 변경도 동일한 PATCH API의 `keyword`로 처리합니다. 기존 저장 리포트를 조회하는 것만으로는 외부 API를 재호출하거나 무료 횟수를 차감하지 않습니다.

이후 리포트를 다시 조회하면 저장된 CPC를 `investmentSimulation.cpc`에, 해당 CPC로 조정된 투자 등급과 사유를 `summary.investmentGrade`·`summary.gradeReason`에 반환합니다. 4단계의 판매가 슬라이더·채널 선택으로 계산한 임시 마진은 투자 등급의 기준 마진을 대체하지 않습니다.
