# Chozy Server 현재 상태

Chozy Server는 위탁 셀러의 상품 소싱 검증을 위한 REST API다. 현재 작업 범위는 Spring 서버이며 운영 연동은 후속이다.

## 구현 상태

| 범위 | 상태 |
| --- | --- |
| 공통 기반 | 공통 성공·오류 응답, 보안·CORS, OpenAPI, DB 없는 기본 프로필과 격리 PostgreSQL 개발 프로필 |
| 계정 | 개발용 일반 가입, 로그인, JWT 재발급·로그아웃, 회원 정보·비밀번호·광고 수신 동의 변경, 회원탈퇴·토큰 무효화 |
| 마이페이지와 홈 | 대시보드와 무료 월간 분석 사용량 조회. 관심상품과 회원 스크리닝 사용량을 각 기능의 저장 데이터에 연결 |
| 홈 공급 조건 우수 상품 | 설정 시 Collector의 `read_supply_home`으로 소싱처별 최신 완료 발행본을 조회한다. 실제 DB에서 발행본 조회 검증은 대기 중이다. |
| 홈 쿠팡 베스트 | 설정 시 Collector의 최신 완료 발행본에서 카테고리, 상품 순위와 전일 변동을 JDBC로 읽는다. 격리 DB에서 API 검증을 마쳤고 운영 연결은 대기 중이다. |
| 홈 네이버 시즌·쿠팡 비교 | 설정 시 Collector의 최신 완료 네이버 발행본을 JDBC로 읽고 동일 기준일의 완료 쿠팡 상품과 비교한다. 격리 DB에서 API 검증을 마쳤고 운영 연결은 대기 중이다. |
| 키워드 스크리닝 | 요청·최근 기록, 쇼핑인사이트 분야, 저장한 키워드의 쇼핑 반응과 점수 재계산 계약 구현. 네이버 데이터 제공자는 미연동 |
| 직접 입력 정밀분석 | 작업·리포트·사용량 경계와 opt-in 시장 분석 엔진 구현. 진행 조회에서 키워드 조회(4)와 시장 데이터 조회(5)를 제공한다. 쿠팡 시장가·네이버 검색광고·데이터랩으로 스냅샷을 생성한다. 쿠팡 검색 호출 오류 시 예상 판매가를 받는 계산 대기 리포트를 저장한다. 엔진 설정 전 503을 반환한다. 검증 환경에서 실데이터 리포트 생성, 공동 예약, 무료 사용량 차감을 확인했다. |
| 상품 URL 정밀분석 | 공개 URL 판별, 도매꾹→도매매 전환, 옵션 검증, 회원 요청·진행 계약 구현. 실제 소싱처 조회 제공자와 분석 엔진은 미연동이며 필요한 요청은 503을 반환 |
| 리포트 | 본인 리포트 상세·최근 기록·점수 의견, 쿠팡 대분류 조회, 추가 입력 저장·재계산 구현. 실제 키워드·옵션 갱신 제공자는 미연동 |
| 관심상품과 알림 | 직접 입력 리포트에서 관심상품 등록·목록·상세·상태 변경·판매 결과 기록·삭제 구현. 알림 설정 조회·변경, 저장된 알림 목록과 개별·전체 읽음 처리 구현 |
| PostgreSQL | 기존 격리 개발 DB에 V1~V12 적용. V12는 작업 진행 단계 저장 컬럼을 추가한다. 운영 DB 적용은 대기다. |

패키지별 책임과 통합 경계는 [BACKEND](BACKEND.md#패키지와-의존-방향)를 참고한다.

## 최신 검증

- **직접 입력 실데이터** (11월 27일): 데이터랩 응답 형식 수정 후 작업 2가 7단계로 완료됐다. 리포트 1에 쿠팡 시장가·네이버 검색량·일간 및 월간 트렌드를 저장했다. 무료 잔여는 3회에서 2회로 줄고 재조회 후 유지됐다. 공동 예약 증가량은 쿠팡 검색 1회, 검색광고 1회, 데이터랩 2회였다. 실패한 분석의 리포트·사용량 미기록도 확인했다. [재현 절차](../README.md#직접-입력-정밀분석-실데이터-검증)
- **최신 회귀** (11월 27일): 기본 91개·격리 DB 통합 79개 통과. V12 신규 설치와 기존 리포트 업그레이드, 분석 진행·시간 초과, 리포트·점수·사용량, 인증·OpenAPI, 공동 예산 함수 권한을 확인했다. 대체 응답에서 공급 추천 빈 결과·연결 실패와 쿠팡 503/429의 계산 대기·차단을 확인했다. 격리 개발 DB의 V11→V12 전후 업무 행 수는 유지됐다.
- **홈 발행본** (11월 26일): Collector DDL을 적용한 PostgreSQL 16.16에서 컬럼 읽기 전용 로그인으로 베스트·시즌·비교 API를 확인했다. 발행 완료 여부, 기본·명시 선택, 전일 비교 결측, 같은 기준일의 중복 제거와 권한 오류를 다뤘다. 공급 추천의 실제 완료 발행본과 운영 DB 연결은 검증 대기다.

## 개발 순서

1. 홈 조회의 운영 발행본 권한과 실제 조회를 확인한다. 정밀분석의 키워드별 쿠팡 비교·Wing 추천·세부 요율, 스크리닝, URL 소싱처, 관심상품 추적과 외부 알림을 실제 데이터에 연결한다.
2. 공개 전 본인인증·DI·소셜 계정, 탈퇴 후 데이터 보존·비식별화·재가입, 운영 공동 호출 예산·DB 역할·배포를 확정하고 검증한다.
